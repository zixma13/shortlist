# The Mist

[Play the demo](https://zixma13.github.io/shortlist/mist/) · [Download the HTML](index.html) · [Back to all demos](../README.md)

A procedural mist-filled street in a **6296byte** standalone HTML file. WebGL2 draws a fullscreen triangle; GLSL computes the environment, fog and lighting, while Web Audio synthesizes ambient sound. No downloaded libraries, images, models, fonts or audio files. The supplied HTML is published without modification.

Use WASD or arrow keys to move/turn, point to look, or press and hold to move. Sound begins after the first key/pointer interaction. The scene lowers rendering resolution when its frame-time estimate is high. No fixed-resolution FPS benchmark has been claimed for this demo. A WebGL2-capable browser is required.
